# Frontend

- Frontend para cadastro/listagem de cliente, evento e ingresso

## Tecnologias utilizadas

- Angular 22.2.0
- TypeScript
- Angular Material 22.2.2
- Vitest 5.0.0
- Node 24.21.0
- npm 12.2.0

## Executar aplicação

```bash
npm install
```

```bash
ng serve
```

Aplicação estará disponível em `http://localhost:4200/`.

## Criar componentes

Lista de comandos do Angular disponíveis:

```bash
ng generate --help
```

Comando para gerar os componentes

```bash
ng generate component component-name
```

## Rodar Build

```bash
ng build
```

Os arquivos serão gerados na pasta `dist/`.

## Executar testes

```bash
ng test
```
