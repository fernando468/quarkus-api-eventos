# Eventos

Aplicação web para autenticação de usuários e gerenciamento de clientes, eventos e ingressos

## Funcionalidades

- Cadastro de clientes e autenticação com JWT
- Consulta de clientes
- Criação, edição e consulta de eventos
- Gerar e consultar de ingressos e alterar o status

## Tecnologias

- **Backend:** Java 25, Quarkus e H2.
- **Frontend:** Angular 22, TypeScript e Angular Material.

O H2 está configurado em memória então ao reiniciar o backend os dados serão perdidos.
