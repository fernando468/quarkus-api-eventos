# backend

- API REST para cadastro/listagem de cliente, evento e ingresso

## Tecnologias utilizadas

- Java 25
- Maven 3.9.12
- Quarkus 3.40.1
- JUnit 5.24.0
- Mockito 5.24.0
- Banco de Dados H2

## Executar a aplicação

```bash
./mvnw quarkus:dev
```
